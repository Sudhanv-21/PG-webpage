# StayNest PG Management

A responsive paying guest and hostel management dashboard for rooms, tenant records, and payment tracking.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

## Current features

- Add room and flat records
- Add tenant details and government ID information
- Tag tenants to room or flat numbers
- Record advance, monthly rent, deposit, and other payments
- Filter rooms by occupancy
- Search tenants
- View payment activity and rent collection status
